# Relax Studio®

A responsive, single-page creative studio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure, content, and SEO/social metadata
- `styles.css` — responsive layout, silver/chrome visual styling, and reduced-motion support
- `script.js` — mobile navigation, current year, and scroll reveal effects

## Preview locally
Open `index.html` in a browser, or run a local static server from this directory.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site and open the URL shown in Settings → Pages.

## Before launch
- Replace the placeholder contact email `hello@relaxstudio.design` in `index.html` with the studio's real contact address.
- Add a real domain and update the canonical URL / social preview metadata when a domain is chosen.
- Add real portfolio projects, client work, and verified social links as they become available.
- If you use a custom domain, add the appropriate DNS records and configure it in GitHub Pages.
